# HareSpark

**滑一下，就換 App。**

macOS 選單列上的 App 切換器，整套操作都在觸控板上完成。

## 這是什麼

HareSpark 常駐在選單列，把觸控板的一次滑動變成 App 切換器。手指放上觸控板、滑一下，
就落在你要的 App 上——不用按 Command-Tab，也不用把游標拉到 Dock。

## 和別的做法差在哪

點 Dock 上的圖示，那個 App 的**每一個**視窗都會一起浮上來，把你原本在看的東西蓋掉。
HareSpark 可以再往下一層：在某個 App 上往上滑，看到它底下的視窗，選一個，
**就只有那一個視窗會浮上來**，其他的留在原地不動。

## 完整的手勢流程

| 手勢 | 會發生什麼 |
| :--- | :--- |
| 手指放著，然後滑動 | 開啟切換器 |
| 左右滑 | 在最近使用的 App 之間移動 |
| 在標了 `^` 的 App 上往上滑 | 打開那個 App 的視窗列表 |
| 再往上滑一次 | 開啟選中的視窗 |
| 在視窗層往下滑 | 回到 App 列表 |
| 在 App 列表往下滑 | 關掉切換器，什麼都不改變 |
| 在視窗層放開手指 | 面板會留在畫面上——用滑鼠點卡片，或按 Esc 關掉 |

用三隻手指啟動（也可以改成四隻）。切換器一旦開了，一、二、三隻手指都能繼續操控。

## 系統需求

- macOS 13.4 以上
- Apple 觸控板——內建的或 Magic Trackpad 都可以
- **輔助使用**權限——必要，HareSpark 靠它讀取觸控板手勢
- **螢幕錄製**權限——選用，開了才會顯示視窗縮圖。
  不給也不影響其他功能，視窗會以圖示呈現。

## 安裝

1. 到 [Releases](../../releases/latest) 下載 `.dmg`
2. 把 HareSpark 拖進「應用程式」資料夾
3. 打開它——會有設定引導帶你走過權限，以及下面講的觸控板衝突

所有版本都用 Apple Developer ID 憑證簽章，並經過 Apple 公證。

## 把觸控板手勢空出來

macOS 自己也用同一組滑動手勢，而且它比 HareSpark 更早收到。設定引導會自動偵測
哪幾個真的衝突，並直接帶你到對應的設定頁。簡單說就是：

> 系統設定 → 觸控式軌跡板 → **更多手勢**，把 **Mission Control**、
> **App Exposé**、**在頁面之間滑動／在全螢幕應用程式之間滑動**
> 移到 HareSpark 沒在用的手指數。

建議的分配是 HareSpark 用三指，系統手勢用四指。

如果你有在用三指拖移，觸發方式會固定成「先放著再滑」，這樣快速三指滑動照樣可以
拖動視窗，跟以前一樣。

## 設定項目

- **手勢**——三指或四指、直接滑或先放著再滑、停留時間、切換速度
- **視窗選擇器**——圖示或卡片、預覽大小
- **外觀**——系統材質或毛玻璃（透明度可調）
- **一般**——跳過沒有視窗的 App、到底端時循環、開機自動啟動、顯示或隱藏 Dock 圖示
- **語言**——跟隨系統、English、繁體中文

HareSpark 會自己更新。它在背景檢查新版本，也可以設定成自動安裝；

## 隱私

觸控板的輸入完全在你的 Mac 上處理，不會傳出去。HareSpark 只有兩種對外連線：
檢查更新，以及每台 Mac 一次的授權啟用。設定裡顯示的機器碼是在本機算出來的，
也只顯示在那裡。
